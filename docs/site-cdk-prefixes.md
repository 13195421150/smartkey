# CDK 套餐前缀

| 卡台套餐 | 本站前缀 |
| --- | --- |
| `plus` | `PLUS-` |
| `pro_5x` | `Pro5X-` |
| `pro_20x` | `Pro20X-` |

卡台原始 CDK 仍为 `ZC-`。本站在发码、同步、列表、复制、导出与卡密换新结果中按套餐显示上述前缀；其他套餐和历史前缀保持原样。

只有已经同步完整原码、且套餐与前缀匹配的卡密才能使用本站前缀。后台从卡台同步完整码后，再从本站复制或导出即可。

原码与本站码共用上游 ID、兑换额度、停用状态、查询记录、Session 绑定和失败诊断；原始卡台记录与本站映射分别保存，不创建第二张可独立消费的卡密。输入前缀不区分大小写，但修改成其他套餐前缀会被拒绝。

回滚到不支持这些前缀的旧后端后，已发出的本站别名无法识别；更新和回滚时应保留别名解析能力。

完成「卡密换新」后，仅接受当前新码。该记录的旧本站码与原始 ZC- 码在本站均失效；卡台官网的原始码不受本站换码影响。详见 [卡密换新](site-cdk-rotation.md)。
